```
① 读收藏夹（拿视频列表）
       ↓  用你的 cookie，直接打抖音收藏接口
② yt-dlp 下视频（只要音频）
       ↓

       ↓
⑥ 写入工作台 videos 条目（带分析结果）
       ↓
⑦ 课表页顺带展示（你要求的：看课表时顺便看观点）
```

### 关于「用你的 cookie 读收藏夹」—— 说明我的边界

你明确说「我可以给你 cookie」，我接受。但我要把话说清楚：

1. **cookie 是你自己的账号凭据**，我会：
   - 只存在服务器 `server/.env`（`chmod 600`，和现有 `AUTH_TOKEN` 同样待遇）
   - **绝不回显到聊天里**、绝不写进代码仓库、绝不传给任何第三方
   - 你随时可以改密码让 cookie 失效
2. **cookie 是有有效期的**（抖音通常几天到几周）。过期后需要你重新取一次。
   我会：
   - 在设置页做一个「cookie 状态」显示，过期前提醒
   - **不允许**因为过期就静默失败 —— 必须明确告诉你「该换 cookie 了」
3. **不伪造请求签名**去绕抖音风控。用 cookie 是「你授权我以你的身份访问」，
   和「破解签名」是两回事，后者我不做。

### 3.1 我在写代码时踩到并修掉的三个接口错误（2026-09-26）

第一版 `transcribe()` 我是凭印象写的，**三个地方都错**。查阿里云官方文档后逐条修正：

| # | 我原来写的 | 官方实际要求 | 不改会怎样 |
|---|---|---|---|
| 1 | 模型 `paraformer-realtime-v2` | **`paraformer-v2`** | realtime 是 WebSocket 流式模型，不接受文件 → 直接失败 |
| 2 | 音频用 `data:audio/m4a;base64,...` 直传 | **必须是公网 HTTP/HTTPS URL**，官方原文「不支持 Base64 编码或本地文件路径」 | 提交即被拒 → 直接失败 |
| 3 | header `X-DashScope-Async: disable` | **`: enable`**（且必填） | 异步任务提交被拒 → 直接失败 |

**第 2 条是设计级的**，不是改个字符串就行：音频必须公网可达，
所以要有个「临时音频托管」。我用的是项目里已有的同款模式
（`/dropimg/` 那种 token 路径 + nginx 静态托管 + 随机文件名），没新造轮子：

- 目录 `/var/www/asrtmp/`，nginx 路由 `/asrtmp/`（挂在 nexus.kotete.xyz）
- 文件名 `secrets.token_urlsafe(24)` 生成，不可猜测
- **转写完成（无论成败）立即 `unlink`** —— 它是公网可见的，多留一秒都是风险
- 仅 GET/HEAD；非音频扩展名 403；目录列表 403

#### nginx 这段被我写错两次，都留了注释钉住

| 错法 | 症状 | 真因 |
|---|---|---|
| 把白名单正则 `location ~` **嵌**在 `location /asrtmp/` 里 | `/asrtmp/x.m4a` 返回 **301** 跳到 `/asrtmp/x.m4a/` | 嵌套正则在 alias 下语义混乱，nginx 把它当目录 |
| 兜底用 `location ^~ /asrtmp/` | **合法音频也 403** | `^~` 匹配后**直接跳过正则求值**，白名单那条永远不生效 |

最终写成两条**平级** location：正则白名单在前、普通前缀 403 兜底在后，
靠 nginx「正则优先于前缀」的规则决定优先级。

实测 8 个用例（2026-09-26）：

| 请求 | 结果 |
|---|---|
| `/asrtmp/x.m4a` | ✅ 200，内容正确 |
| `/asrtmp/x.txt`（非音频） | ✅ 403 |
| `/asrtmp/x.m4a/`（带斜杠） | ✅ 403 |
| `/asrtmp/`（目录列表） | ✅ 403 |
| `/asrtmp/nope.m4a`（不存在） | ✅ 404 |
| `/asrtmp/%2e%2e%2fsecret.txt`（编码穿越） | ✅ 404 |
| POST / PUT 到音频 | ✅ 403 |

### 3.2 DashScope 端点路径已验证（用假 key，期望 401 而非 404）

| 端点 | 返回 | 含义 |
|---|---|---|
| `POST services/audio/asr/transcription` | 401 InvalidApiKey | ✅ 路径存在 |
| `GET tasks/{task_id}` | 401 InvalidApiKey | ✅ 路径存在 |
| `POST services/aigc/text-generation/generation` | 401 InvalidApiKey | ✅ 路径存在 |

> 3 个端点都返回 401（而非 404），证明**我的路径写对了**、只差有效 key。
> 这是我在没有你凭据的情况下能推到的最远边界。

### 3.3 ASR 结果解析：优先用整段文本，不是分句拼接

官方返回的 `transcription_url` 指向的 JSON 里有两个可用字段：
`transcripts[].text`（完整识别文本）和 `transcripts[].sentences[].text`（分句）。
**优先用前者** —— 分句再拼会丢掉标点和跨句上下文，拼出来更差。
分句只作为兜底（`transcripts[].text` 缺失时）。

### 成本闸门（防止「跑完才发现扣钱」）

实现在 `server/tools/douyin_pipeline.py`：

| 机制 | 作用 |
|---|---|
| 按**官方返回的计费时长**记账（`usage.duration`） | 不靠文件大小估算，误差会算错钱 |
| 账本记月份，跨月读时归零 | 对应官方额度重置 |
| 批量前预估并拦截 | 超预算**连第一条都不跑** |
| 每次运行打印用量 | 你随时知道还剩多少 |

默认预算 = 免费额度。想超额需**显式**放宽 `--budget-seconds`。
另建议在控制台开启 **「免费额度用完即停」**（云端双保险）。

14 项计量测试见 `server/tools/test_usage.py`。
