# 收藏夹取数：三条路的技术结论（2026-09-26 实测）

> 这份文件回答一个问题：**「下载你收藏夹里的视频」这件事，技术上到底卡在哪、怎么过。**
>
> 结论是实测出来的，不是读文档读出来的。每条都标了证据。

---

## 一、先说结论（如果你只看一段）

抖音的收藏夹接口有**三层校验**，光有 cookie 走不通：

| 层 | 要求 | 我实测到的证据 |
|---|---|---|
| 1 | HTTP header 里必须有 **UIFID** | 不带 → `Uifid Not Found`；带上 → 报错变成 `Signature Not Found`（说明这层过了） |
| 2 | URL 参数里必须有 **`a_bogus` 签名** | 用现成库生成后仍然报 `Signature Not Found`（因为第 3 层） |
| 3 | 签名必须**用你浏览器当前时刻的环境**算出来 | 查表法映射表只到 2024-01-02，现在 2026-09 → 必然算错 |

**所以：纯「给 cookie」的方案全部走不通。** 必须让**浏览器**参与。

## 二、我试过并排除的方案（省你别再试）

### ❌ 方案 1：直接请求接口 + cookie

```
GET https://www.douyin.com/aweme/v1/web/aweme/listcollection/?count=10&cursor=0
```

**结果：** `403 Blocked by ArgusSecurityPlugin Uifid Not Found`

**为什么不行：** 抖音在 cookie 之外还查一个 HTTP header 叫 `UIFID`，
以及一个叫 `a_bogus` 的签名参数。这是它的反爬系统（代号 Argus）。

> 附带证明：路径本身是对的 —— 它返回 403 而不是 404。

### ❌ 方案 2：纯 Python 算 a_bogus（mafqla/douyin-api）

这个 GitHub 项目声称「100% 纯 Python 实现 a_bogus 签名，无需 Node.js」。

**我实际跑了，三个发现：**

| 发现 | 细节 |
|---|---|
| 三种签名方式都能生成 | 查表法 192 字符 / JS 算法 164 字符 / bdms 204 字符 |
| **但查表法的映射表只覆盖 2024-01-01 ~ 2024-01-02** | 100 个样本、约 28 小时。现在是 2026-09，**差两年半** |
| 用生成的签名请求，仍然 `Signature Not Found` | 服务端不认 |

它自己的文档写着：**「超出范围会失效，需要扩展映射表」**。
要让它能用，得自己搭浏览器环境重新采 9000+ 样本 —— 那是另一个大项目。

**另外它依赖一个已废弃的 httpx 版本**（`httpx.Client(proxies=...)`，
新版已移除该参数），说明这个项目本身维护得不好。

### ❌ 方案 3：解析你贴的分享口令

你贴的两条是抖音口令：`##BtPixQB63a9##` / `##Ttq7jpH63a9##`

**我试过：** 当成短链请求 → 返回的是**抖音的 WAF 挑战页**
（`waf_js` / `waf-jschallenge` 脚本），不是内容。口令必须在抖音 App 内解析。

### ❌ 方案 4：yt-dlp 直接下收藏夹

`yt-dlp` 有原生 `Douyin` 提取器，但它只支持**单个视频 URL**，
不支持「列出某人的收藏夹」。读取列表是应用层的事，不是下载器的事。

### ✅ 方案 5：让浏览器自己把数据交出来（推荐）

**关键洞察：漏洞不在「算签名」，在「不该自己算」。**

浏览器能算出正确签名，因为它就在抖音的页面里、有正确的环境。
**所以让浏览器在抖音页面里执行一段脚本，把结果交给我** —— 不碰签名。

## 三、推荐方案：浏览器控制台提取（一次搞定）

### 优点

| 项 | 说明 |
|---|---|
| **绕开全部三层校验** | 不自己发请求，借用页面已有的登录态和签名能力 |
| **不装任何扩展、不用开发者工具翻请求** | 只开一个控制台、粘一段代码 |
| **一次性拿到全量列表** | 不是「复制 cookie 行」那种易错操作 |
| **对收藏夹只读** | 代码里没有任何写操作 |

### 操作步骤（照着做，约 3 分钟）

**第 1 步：打开收藏夹页面**

电脑 Edge → 打开抖音 → **扫码登录**（如果没登录）
→ 点右上角头像 → **「我的收藏」**
→ **重要**：在收藏夹页面里**往下滚几屏**（让列表加载出来）

**第 2 步：打开控制台**

按 **F12** → 点顶部 **「控制台 / Console」** 标签

**第 3 步：粘代码**

我会给你一段代码，复制粘贴进去，按回车。

**第 4 步：它会自动下载一个文件**

代码会把结果存成 `douyin-favorites.json` 下载到你电脑上。

**第 5 步：把文件放到项目目录**

放到 `C:\Users\HXT\Desktop\` 就行，然后告诉我「放好了」。

## 四、关于隐私

我要明确写清楚，因为这条涉及你的账号：

| 我拿到什么 | 用来做什么 | 不做什么 |
|---|---|---|
| 你收藏夹的**视频列表**（标题/链接/作者/时长） | 挑出成长类视频来分析 | ❌ 不发布/评论/点赞 |
| 你的**登录态**（仅在导出那一刻） | — | ❌ 我不需要你的 cookie，**新方案根本不用传 cookie** |
| 视频音频（仅收藏的那几条） | 转文字、提观点 | ❌ 不留存，转写完立即删 |

**新方案的一个附带好处：不需要你把 cookie 交给我。**
之前的方案要 cookie，等于把「以你身份登录」的凭据交出去 ——
能读收藏夹，也能删收藏。**浏览器提取方案绕开了这个风险。**
