## 三、这个脚本干了什么（你可以自己核对）

脚本在 `docs/tools/douyin-favorites.user.js`，随便看。

| 它做 | 它**不**做 |
|---|---|
| ✅ 挂 XHR + fetch 两个钩子，把抖音页面**自己**调的收藏夹接口返回抄一份 | ❌ 不自己构造请求、不算签名 |
| ✅ 按 `aweme_id` 去重、只留有用字段 | ❌ 不上传任何数据到第三方 |
| ✅ 生成 JSON 下载到本地 | ❌ **不调用任何写接口**（不收藏/取消/点赞/评论） |
| ✅ 面板上如实显示「钩子触发状态」 | ❌ 不在页面上做任何视觉改动 |

**关键点：它不碰 cookie，不碰签名算法。**
抖音页面自己会调那个接口，脚本只是抄结果 —— 服务端看到的是「你正常浏览收藏夹」。

**为什么不用自己算签名：** 抖音的反爬要求签名匹配**当前时刻的浏览器环境**。
网上那些纯 Python 方案用的是查表法，**映射表停在 2024 年初**（我实测过，见
`docs/COLLECTION-ACCESS.md`），早就失效。让浏览器自己算才是唯一稳的路。

**只读性验证：**
```bash
# 应该没有任何输出
grep -nE "method:\s*['\"](POST|PUT|DELETE)|\.open\(['\"](POST|PUT|DELETE)" \
  docs/tools/douyin-favorites.user.js
```

**逻辑正确性验证**（在假 DOM 里真跑过，不需要浏览器）：
```bash
cd docs/tools && node test-userscript.js douyin-favorites.user.js
# 实测输出：3 页 10 条（含 1 条重复）→ 导出 9 条，去重生效，字段齐全
```

## 五、拿到之后我做什么（顺序不能乱）

1. **先只跑 1 条** —— 从你收藏里挑一条，跑完整链路
2. **把结果原样给你看**（一句话观点 + 3 个要点 + 标签）
3. **你说行，我再批量**；你说不行，我调 prompt 重跑
4. 批量（100 条约 0 元，ASR 只用掉免费额度的 33%）
5. 写进工作台 → 课表页显示

> 第 1~3 步是刻意设计的：**先证明一条能看，再批量。**
> 不想批量跑完 100 条、你一看摘要全是废话 —— 那浪费的是你的额度和时间。

## 六、失败时怎么办

**先忽略抖音自己的报错。** 控制台里会有很多红字，比如：

```
Access to XMLHttpRequest at 'https://imapi.douyin.com/v1/stranger/get_conversation_list'
... has been blocked by CORS policy
```

**这是抖音自己的私信接口在报错，跟我们无关。** 抖音自己的代码没处理好，
每个用户都会看到。不用管。

**脚本真出问题时的样子：**

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 面板一直「已捕获 0 条」，钩子显示 `XHR ⏳ fetch ⏳` | 抖音换了别的请求方式 | 把 F12 → Network 里收藏夹请求的名字截图给我 |
| 钩子显示 `XHR ✅` 但数字不涨 | 接口路径变了 | 同上 |
| 面板根本没出现 | 不在收藏夹页面 / 脚本没生效 | 截图给我看右上角篡改猴图标有没有数字角标 |

**兜底方案（最笨但一定成）：**
手动把收藏夹滚到底，我给你另一段「提取当前页面所有视频链接」的代码。

**不管哪种失败，你会拿到一个具体报错，不是一个「失败了」。**
