# 怎么把 cookie 和 API Key 给我（操作手册）

> 这两样是整条链路**唯一**还缺的东西。服务器代码已经就绪并验证过。
> 全程约 5 分钟。

---

## 一、抖音 cookie（我需要它来读你的收藏夹和下载视频）

### 前提
抖音的收藏夹接口**必须登录才能读**。所以我需要你浏览器里已登录状态的 cookie。

### 方案 A：电脑浏览器（推荐，最省事）

1. 电脑 Chrome / Edge 打开 **https://www.douyin.com**，**扫码登录**
2. 按 **F12** 打开开发者工具
3. 切到 **Network（网络）** 标签
4. 地址栏回车刷新页面，**等列表出现内容**
5. 在请求列表里随便点一条发往 `douyin.com` 的请求
6. 右侧找到 **Request Headers（请求标头）** → 找到 **`Cookie:`** 那一行
7. **整行的值全部复制**（很长，几千个字符，全选复制）
8. 压缩成一个文件发我（见下方「三、怎么把东西给我」）

> ⚠️ 如果找不到 Cookie 行：Network 面板右键 → 勾选 `Headers` 相关项，
> 或者换个标签叫「Headers / 标头」的位置看。

### 方案 B：如果电脑上没有登录抖音

用手机也行，但麻烦些。**优先用方案 A**。
如果你 iPhone Safari 已登录抖音网页版，可以试着在手机上操作，
但 Safari 手机版没有开发者工具，得靠别的办法导出 cookie —— 不值得折腾。

### cookie 的有效期
- 抖音 cookie 通常**几天到几周**过期
- 过期后我会明确告诉你「该换 cookie 了」（代码里已经写死这条路径，不会静默失败）
- 你随时可以改抖音密码，让这份 cookie 立即失效

### 我拿它做什么 / 不做什么

| 做 | 不做 |
|---|---|
| ✅ 读你的**收藏夹列表**（只读） | ❌ **绝不**取消/删除/修改你的任何收藏 |
| ✅ 下载你收藏的视频（只要音频） | ❌ 不上传视频到任何地方 |
| ✅ 存在服务器 `server/.env`，`chmod 600` | ❌ 不写进代码仓库、不回显到聊天、不给第三方 |

## 二、DashScope API Key（免费额度实测够用，且 ASR 每月重置）

### 为什么要它
抖音视频里**没有文字**，只有语音。要拿到「观点」，必须：
1. **语音转文字**（ASR）—— 用阿里云 Qwen Paraformer
2. **文字提炼观点**（LLM）—— 用阿里云 qwen-plus

这两个都在阿里云百炼（DashScope）平台，**不需要 GPU**。

### 免费额度到底有多少（2026-09-26 查证官方文档）

| 模型 | 免费额度 | 有效期 | 超出后单价 |
|---|---|---|---|
| **Paraformer-V2**（转写） | **10 小时/月** | **每月 1 日 0 点自动重新发放** | 0.6 元/小时 |
| **qwen-plus**（提炼） | 100 万 Token | 90 天，**不续发** | 输入 0.8 / 输出 2.0 元每百万 Token |

> ⚠️ 关键区别：文本模型的免费额度是「一次性 90 天」，
> 而 **ASR 是每月重置的** —— 这是阿里云文档里明确写的例外条款，
> 对「每月慢慢消化收藏夹」这种用法非常友好。

### 你的场景算下来是 0 元

按 100 条视频、平均 2 分钟估算：

| 项 | 用量 | 免费额度 | 结论 |
|---|---|---|---|
| ASR 转写 | 100 × 2 分钟 = **3.3 小时** | 10 小时（月月重置） | ✅ 只用掉 33% |
| LLM 提炼 | 约 **13.5 万** Token | 100 万 | ✅ 只用掉 13.5% |
| | | **合计** | **✅ 0 元** |

就算你的视频平均 5 分钟（100 条 = 8.3 小时），也**还在免费额度内**。

### 用完免费额度怎么办（已经做好防护）

我没有把这个风险留给你去发现。pipeline 里有**成本闸门**：

1. **本地记账**：每次转写按阿里云返回的**官方计费时长**累计到 `tools/usage.json`
2. **跨月自动归零**：账本记录月份，跨月读取时自动清零（对应官方额度重置）
3. **开跑前预估并拦截**：批量时先算「这批要多少小时」，超预算就**拒绝启动**，
   连第一条都不会跑
4. **跑完报账**：每次运行都打印「本月已用 X / 免费 10 小时」

默认预算就是免费额度（10 小时）。想超额也能用，但要**显式**放宽：

```bash
# 默认：超了就停，不会产生任何费用
python3 douyin_pipeline.py --urls-file /tmp/urls.txt

# 明确允许最多花 2 元（约 3.3 小时）时：
python3 douyin_pipeline.py --urls-file /tmp/urls.txt --budget-seconds 48000

# 完全不限制（不推荐）：
python3 douyin_pipeline.py --urls-file /tmp/urls.txt --budget-seconds 0
```

**另外建议你在阿里云控制台做一件事**（我没法替你操作）：
免费额度页面 → 找到 Paraformer → 打开 **「免费额度用完即停」**。
开了之后，额度耗尽会返回 403 而不是继续扣费。这是双保险 ——
即使我的记账有偏差，云端也不会偷偷扣你的钱。

### 怎么拿 Key

1. 打开 **https://bailian.console.aliyun.com/**
2. 用**支付宝或淘宝账号**登录（1 分钟）
3. 首次进入会提示**开通「百炼」服务**，点开通
4. ⚠️ **注意地区**：免费额度**只在「华北2（北京）」地域有**，
   你截图里那个 `cn-beijing` 是对的
5. 左侧 **API-KEY** → **创建我的 API-KEY**
6. ⚠️ ASR 类模型需要**在业务空间里单独开通权限**才能调用
   （官方文档明确提到这点，如果调用报权限错，回来这里开通）
7. 复制那串 `sk-xxxxxxxxxxxx...`

### 怎么给我
**不要**直接发到聊天里。用下方「三、怎么把东西给我」的方式。

## 三、怎么把东西给我（重要：别直接贴在聊天里）

聊天记录会被保存。**凭据不要贴在对话里。**

### 推荐方式：写成文件放到项目目录

在你的电脑上新建一个临时文件，比如 `C:\Users\HXT\Desktop\nexus-credentials.txt`：

```
DASHSCOPE_API_KEY=sk-你复制的key
DOUYIN_COOKIE=你复制的整行cookie
```

然后告诉我「凭据文件放好了，在桌面上」。

我会：
1. 读它
2. 写进服务器 `server/.env`（`chmod 600`，只有 root 可读）
3. **立即删除你桌面上那个明文文件**
4. **在聊天里只回报「已配置，长度 N 字符」，不回显内容**

### 备选：直接告诉我文件路径
如果你已经放在别的位置，直接把路径告诉我就行。

---

## 四、拿到之后我会做什么（顺序不能乱）

1. **先只跑 1 条视频** —— 你最想复看的那种，随便发我一个抖音链接
2. 我跑完整链路：下载 → 转写 → 提炼
3. **把结果原样给你看**（一句话观点 + 3 个要点 + 标签）
4. **你说行，我再碰收藏夹**；你说不行，我调 prompt 重跑
5. 质量确认后才读收藏夹列表（先只读，确认能拿到 100+ 条）
6. 批量分析 → 写进工作台 → 课表页显示

> 第 1–4 步是刻意设计的：**先证明一条能看，再批量。**
> 我不想批量跑完 100 条，你一看摘要全是废话 —— 那浪费的是你的额度和我的时间。
