## 二、导出收藏夹（约 3 分钟）

### 为什么不能靠我一个命令搞定

抖音的收藏夹接口有三层反爬校验（UIFID header + a_bogus 签名 + 签名必须匹配当前时刻）。
**前两层我能伪造，第三层不能** —— 签名要用你浏览器当前的运行环境算出来。
所以**必须让你的浏览器参与**。这不是我在推活，是物理限制。

细节和实测证据：`docs/COLLECTION-ACCESS.md`

### 步骤

**① 打开收藏夹页面**

电脑 Edge → https://www.douyin.com → 扫码登录（未登录的话）
→ 右上角头像 → **「我的收藏」**

**② 先往下滚几屏**

让收藏列表真正加载出来。不滚的话后面没数据可截。

**③ 打开控制台**

按 **F12** → 点顶部 **「控制台 / Console」** 标签

**④ 粘代码**

打开文件 `docs/tools/export-favorites.js`，**全选复制**，
粘进控制台，按 **回车**。

**⑤ 继续往下滚**

右下角会出现一个黑色小浮层显示进度。
**你在页面上继续往下滚**，它会在后台自动收集 —— 滚到底就收集完。

**⑥ 点导出**

浮层上会出现一个蓝色按钮 **「导出 N 条」**，点它。
浏览器会下载 `douyin-favorites.json`。

**⑦ 把文件放桌面，告诉我**

```
C:\Users\HXT\Desktop\douyin-favorites.json
```

然后说一句「放好了」就行。

## 三、这个脚本干了什么（你可以自己核对）

脚本在 `docs/tools/export-favorites.js`，一共 130 行，随便看。

| 它做 | 它**不**做 |
|---|---|
| ✅ 挂一个 XHR 监听器，把你翻页时页面自己的接口返回**抄一份** | ❌ 自己构造请求、自己算签名 |
| ✅ 去重、剔掉用不上的字段 | ❌ 上传任何东西到第三方 |
| ✅ 生成一个 JSON 文件下载到本地 | ❌ **不调用任何写接口**（不收藏/取消/点赞/评论） |

**关键点：它不接触你的 cookie，也不碰签名算法。**
抖音页面自己会调那个接口，脚本只是把返回结果截下来 ——
服务端看到的是「你正常浏览收藏夹」，没有任何区别。

**你可以随时验证它是只读的**：搜索一下代码里有没有 `POST` / `PUT` / `DELETE`。
没有。

## 四、隐私交代

| 数据 | 我拿到之后 |
|---|---|
| 收藏夹列表（标题/链接/作者/时长） | 只用来挑出成长类视频。不发布、不评论、不点赞 |
| 视频音频（仅选中的几条） | 转文字用。**转写完立即删**，最多在服务器上存在几分钟 |
| 你的 cookie | **新方案根本不需要 cookie** —— 这是它比旧方案好的地方 |

旧的「给 cookie」方案等于把「以你身份登录」的凭据交出去，
能读收藏夹也能删收藏。**浏览器提取方案绕开了这个风险。**

## 五、拿到之后我做什么（顺序不能乱）

1. **先只跑 1 条** —— 从你收藏里挑一条，跑完整链路
2. **把结果原样给你看**（一句话观点 + 3 个要点 + 标签）
3. **你说行，我再批量**；你说不行，我调 prompt 重跑
4. 批量（100 条约 0 元，ASR 只用掉免费额度的 33%）
5. 写进工作台 → 课表页显示

> 第 1~3 步是刻意设计的：**先证明一条能看，再批量。**
> 不想批量跑完 100 条、你一看摘要全是废话 —— 那浪费的是你的额度和时间。

## 六、失败时会发生什么

**脚本不工作的情况（我预判到的）：**

| 症状 | 原因 | 怎么办 |
|---|---|---|
| 浮层一直显示「等待接口响应」 | 可能收藏夹用了别的接口路径 | 把 F12 → Network 里的请求名字截图给我，我改匹配规则 |
| 滚到底但数字不涨 | 自动翻页被拦 | 用兜底方案（见下） |
| 报 CORS / 跨域错误 | 不会发生（脚本不发请求） | — |

**兜底方案（最笨但一定成）：**
手动把收藏夹**滚到底**，然后我给你另一段「提取当前页面所有视频链接」的代码。
一次拿一批，100 条滚几次。确定性最高。

**不管哪种失败，你会拿到一个具体报错，不是一个「失败了」。**
