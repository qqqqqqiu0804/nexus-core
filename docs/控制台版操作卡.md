# 抖音收藏夹导出 · 控制台版操作卡

> 篡改猴在你电脑上的站点权限出了问题（Edge 层拒绝，篡改猴设置页里查不到记录）。
> **这条路绕开篡改猴，直接粘贴一次就能导出。** 只需要跑一次。

---

## 一、操作（60 秒）

### 第 1 步：打开抖音收藏页

Edge 打开抖音 → 点头像 → **「我的收藏」**

地址栏应该长这样（关键是 `favorite_collection`）：

```
https://www.douyin.com/user/self?...&showTab=favorite_collection
```

### 第 2 步：打开控制台

按 **F12** → 点上面的 **「控制台」**（Console）标签

> 如果控制台里有一堆红字，**不用管**。抖音页面本来就会报一堆自己的错。

### 第 3 步：粘贴脚本

1. 用记事本打开 `docs/tools/console-export.js`
2. **全选**（Ctrl+A）→ **复制**（Ctrl+C）
3. 回到浏览器控制台，光标点在最下面那行输入框
4. **粘贴**（Ctrl+V）→ 按 **回车**

> ⚠️ 第一次粘贴时 Edge 可能弹出提示让你输入 `allow pasting` 才允许粘贴。
> 照着输入 `allow pasting` 回车，然后再粘一次。

成功的话控制台会输出：

```
[nexus] 收藏夹导出已启动（控制台版）
  · 面板在页面右下角
  · 命令：__nexusDyStat() 看状态、__nexusDyExport() 手动导出
  · 只读，不发任何写请求
```

**右下角会出现黑色面板。**

### 第 4 步：滚一滚，点进去

**⚠️ 重要：脚本是页面加载后才注入的，所以页面刚才发过的请求你收不到。**
按面板提示操作即可：

| 面板显示 | 含义 | 你该做什么 |
|---|---|---|
| 「还没收到收藏夹数据」 | 正常，刚注入 | **往下滚一屏** |
| 「发现 N 个收藏夹分组」 | ✅ 认出你的收藏夹了 | **点进一个收藏夹**（比如「猛学」） |
| 「视频 N 条」 | ✅ 正在收视频 | **继续往下滚** |
| 「已到底部，可以导出了」 | ✅ 收完 | **点蓝色按钮** |

### 第 5 步：拿文件

点按钮后会下载 `douyin-favorites.json`。

**放到桌面** `C:\Users\HXT\Desktop\`，然后跟我说一声。

## 二、为什么这版能用而篡改猴不能用

| | 篡改猴版 | 控制台版 |
|---|---|---|
| 注入方式 | 扩展自动注入 | **你手动粘贴** |
| 依赖 | ❌ 依赖扩展站点权限 | ✅ **不依赖任何扩展** |
| 持久性 | 装一次永久 | 刷新就没了（**但你只需跑一次**） |
| 功能 | 完全一样 | 完全一样（截获 → 去重 → 导出） |

**两个版本的核心逻辑是同一套**：挂 XHR + fetch 钩子，把抖音页面**自己**调的
收藏夹接口返回抄一份。都不算签名、不碰 cookie、不发写请求。

| 最近接口显示 | 含义 | 怎么办 |
|---|---|---|
| （暂无） | 页面还没发收藏夹请求 | 往下滚 |
| 有路径但不是 collect | 接口名和我猜的不一样 | **截图给我，我改匹配** |
| 有 collect 但数字不动 | 数据形态没认出来 | 截图给我，我改解析 |

**卡住了就截图给我**（要带上整个面板和「最近接口」那几行）。

如果连面板都没出现，在控制台输入这个按回车：

```js
__nexusDyStat()
```

- 报 `undefined` → 脚本没粘成功，重来一次第 3 步
- 返回一个对象 → 脚本在跑，把返回值截图给我
